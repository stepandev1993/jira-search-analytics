# Privacy Policy

Effective date: 2026-04-25

## Overview
Jira Search Analytics is a Chrome extension that visualizes Jira search results on your Jira Issue Navigator page.

## What data is accessed
The extension reads issue metadata from your current Jira search results, including fields required to build charts and tables (for example: status, assignee, priority, versions, labels, dates, and similar issue fields).

## How data is used
Data is used only to:
- build charts and tables in the extension UI;
- export the currently displayed analytics view as a PNG image.

## Data transfer and storage
- No analytics data is sent to external servers by this extension.
- No analytics data is sold.
- No analytics data is shared with third parties.
- No analytics data is used for advertising.
- Processing is performed locally in the browser session.

## Permissions
The extension requests host access to Jira Issue Navigator pages:
- `https://*/issues`
- `https://*/issues/`
- `https://*/issues/*`

This is required only to read issue metadata from your Jira search results and render local visualizations.
